Where the link goes — you choose the words. Wrap the exact words that should become the link in {{link:…}}. The recipient sees your sentence unchanged, with only those words clickable. Starting from “…remediation details are available here.”:

Link on here  →  …details are available {{link:here}}.
Link on available  →  …details are {{link:available}} here.
Link on both  →  …details are {{link:available here}}.
Different wording  →  …details are {{link:available in the audit report}}.
Several links in one message  →  {{link:first}} and {{link:second}} both work.

{{link}} with no words links the word here. A blank line starts a new paragraph; a single line break becomes a line break. With no marker at all, the link falls back to the last standalone here — which is why the message already registered works unchanged.

The link URL is not typed here. It always comes from the report tab cell a11y:https://…, so each site links to its own document. The condition is any keyword you like — a11y, link, ADA Review — just put the same word in the cell. A cell with the word on its own (no link) still adds the message, unlinked.

One note can go to both sheets. Tick the sheets you want it on — adding or editing writes the same message to each of them, so the two can never drift apart. Unticking a sheet and saving does not remove it from that sheet; use Remove for that.
